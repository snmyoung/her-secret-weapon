# Her Secret Weapon

**Her Secret Weapon** is a digital concept brand page designed to celebrate the power, presence, and complexity of modern women. More than just a beauty line, it’s a statement: women carry worlds — and sometimes a slingshot.

This multi-page HTML/CSS project features a clean layout with rotating affirmation-style taglines, interactive design elements, and empowering product concepts that blend beauty with strategy.

---

## Features

- **Rotating Empowerment Banner**  
  Animated quotes cycle through curated messages that reflect strength, resilience, and multitasking grace.

- **Responsive Navigation**  
  A bold navbar with custom Font Awesome icons tailored to feminine strength and style.

- **Product Mockup Gallery**  
  Conceptual product cards represent a beauty line with a twist — from hidden defense tools to self-care with utility.

- **Internal + External CSS**  
  Clean separation of global vs. local styles to reflect scalable brand design.

- **jQuery-Powered Interactivity**  
  Simple, elegant animations to enhance UX without overwhelming the message.
